# Reference clone packages

Each video dropped into chat is converted into a durable package:

- `<id>/reference.json` — measured source timing, camera, motion, composition, audio punctuation, comedy/retention mechanics, and originality boundaries.
- `<id>/clone-blueprint.json` — automatically compiled production blueprint using the locked Content Control character system.
- `<id>/scene-plan.json` — scene-specific original adaptation created during production.
- rendered proof and QA receipts are produced downstream before any review candidate is accepted.

The clone path preserves transferable animation/editing grammar, not another creator's exact character identity, dialogue, signature joke, logo, or traced frames.

Publication remains disabled.
